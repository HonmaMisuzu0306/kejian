## 课间 v1.0.0

“课间”的首个正式版本现已同时提供 Android APK 与手机优先 PWA。它是一套完全本地运行的校园时间管理终端，覆盖课表截图导入、人工校对、周课表、今日安排和个人日程。

### Android 正式版

- 新增 Capacitor 8 Android 原生容器。
- 提供正式签名的 `kejian-v1.0.0.apk`，支持 Android 7.0 及以上版本。
- 使用原创自适应应用图标和工业终端启动画面。
- APK 内置完整网页资源，不依赖开发服务器即可启动。
- 应用数据保存在手机本地，不需要账号或后端。

如果此前安装过文件名带 `-test` 的调试测试包，请先卸载测试包再安装正式版，因为两者的签名不同。

### 课表与截图导入

- 选择一张或多张课表截图，确认学期和教学周。
- 查看明确标记的识别草稿，并添加、编辑或删除课程。
- 支持离散周次、连续节次、重复课程合并和冲突检测。
- 导入后可在七天、11 节的周课表中查看，并可撤销最近一次导入。
- 课程、学期、导入记录和个人日程均保存在本地。

### 个人日程

- 新增独立“日程”入口与 `06:00–24:00` 单日时间轴。
- 课程和个人日程在同一时间轴中显示。
- 支持日程标题、日期、时间、地点、备注和颜色的创建、编辑与删除。
- 自动检测日程之间以及日程与课程之间的冲突。
- 今日页会合并课程与个人日程，并统一计算下一项安排。

### 视觉与体验

- 使用原创“高明度工业终端”视觉系统。
- 手机采用五入口底部控制栏，桌面采用固定侧栏。
- 支持 360–1440px 响应式布局、底部安全区和减少动效模式。
- 灰白阅读区、黑色状态面板与克制的信号黄色保持清晰的信息层级。

### 数据与隐私

- 无账号、无云同步，不收集教务系统账号、密码或 Cookie。
- 截图不会上传，也不会在确认导入后保留。
- APK、不同浏览器及不同域名拥有各自独立的本地数据。
- 可在设置页导出 JSON 档案备份。

### 当前限制

截图识别仍是明确标记的演示实现，不会真正读取截图文字。任意图片都会生成参考课程草稿，保存前必须人工校对。当前也尚未实现真实 OCR、重复日程、系统通知、JSON 恢复、日程文件导入或跨设备同步。
