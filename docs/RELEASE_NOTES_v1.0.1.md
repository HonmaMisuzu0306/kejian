# 课间 v1.0.1 · 课表扫描实验版

这个预发布版本首次让“课间”真正读取课表截图：课程位置与连续节次由网格和色块检测获得，课程名称及教室由设备本地中文 OCR 生成草稿，再交给用户校对后保存。

## 新增功能

- 新增南信大移动教务系统竖屏周课表适配器。
- 自动检测周一至周日、第 1–11 节以及连续课程块。
- 本地识别课程名称和教室，并标记低置信度或缺失字段。
- 导入页显示 OCR 初始化、图片序号和逐课程识别进度。
- 多张截图继续支持周次合并、冲突检查、编辑、删除、补录与撤销。
- OCR worker、兼容核心和简体中文模型随 PWA 与 APK 打包，不依赖远程识别服务。

## 隐私

- 截图只在手机或浏览器本地处理，不会上传。
- 原图只保留在当前导入页面的内存中，离开页面后释放。
- 不需要教务系统账号，不读取账号、密码或 Cookie。

## 实验范围与限制

- 目前只适配南信大移动教务系统的完整竖屏周视图。
- 横屏、裁切截图、不同学校或页面版式尚未支持。
- 中文小字、相似汉字和教室编号仍可能识别错误，导入前必须逐项对照原图。
- 周次来自用户在上传页的确认，不会根据一张截图推测整个学期。
- 首次识别需要初始化约 14 MB 的离线 OCR 资源；低端手机可能需要数十秒。

## 验证

- 参考截图在 Edge 手机尺寸中检测到 11 个课程块，并成功进入校对流程。
- 37 项单元测试通过，包含版式范围、连续课程合并、相邻课程拆分、未命名草稿隔离和 OCR 文本解析。
- 7 个浏览器端到端场景通过，覆盖本地 OCR 导入、编辑、重复导入、撤销、离线刷新与响应式布局。
- 正式 APK 构建、签名和 ZIP 对齐结果以本次发布附件校验为准。
