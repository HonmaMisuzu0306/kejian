## 阶段目标

把“课间”从只查看课程的课表扩展为校园日程工具。用户可以在一天的任意时间段创建个人日程，并在同一时间轴中同时看到课程与个人安排。

本阶段完成日程数据闭环和移动端日视图，不包含云同步、系统推送、复杂重复规则、真实 OCR 或 APK 打包。

## 数据模型

新增独立的日程模型，不把个人日程伪装成课程，也不将课程展开复制成大量事件：

```typescript
type ScheduleEvent = {
  id: string
  title: string
  date: string
  startTime: string
  endTime: string
  location?: string
  notes?: string
  color: string
  createdAt: string
  updatedAt: string
}
```

- `date` 使用本地 `YYYY-MM-DD`。
- `startTime`、`endTime` 使用 24 小时制 `HH:mm`。
- 课程继续由 `CourseMeeting + Semester` 按日期推导，不复制进 `ScheduleEvent`。
- 更新本地数据版本，并兼容已有 v1 数据；旧用户刷新后课程和导入记录不能丢失。
- JSON 档案导出应自动包含个人日程。

## 功能要求

### 1. 日程页面

新增一级入口“日程”，手机底部导航和桌面侧栏均可进入。

页面包含：

- 当前选择日期、星期和教学周。
- 前一天、今天、后一天切换，以及日期选择器。
- 06:00–24:00 日时间轴，具有小时刻度和半小时创建区域。
- 课程块与个人日程块同时显示。
- 课程块保持课程颜色和“课程”来源标签。
- 个人日程使用独立颜色和“日程”来源标签。
- 点击空闲半小时区域时，以该时刻创建默认一小时日程。
- 点击课程打开现有课程编辑器；点击个人日程打开日程编辑器。
- 显示当天课程数、个人日程数和冲突数。
- 当天没有任何安排时仍保留可点击的时间轴，不只显示空状态。

### 2. 日程编辑器

支持创建、修改和删除个人日程：

- 标题（必填）
- 日期（必填）
- 开始时间（必填）
- 结束时间（必填，必须晚于开始时间）
- 地点
- 备注
- 颜色

要求：

- 手机使用底部抽屉式编辑器，桌面使用居中对话框。
- 删除必须经过明确确认。
- 保存、错误和删除后给出反馈。
- 关闭弹窗后恢复之前的焦点。
- 输入框和操作按钮满足触控尺寸要求。

### 3. 冲突检测

检测同一天内：

- 个人日程与个人日程重叠。
- 个人日程与课程重叠。

冲突不会强制阻止保存，但必须：

- 在日程页显示红色状态提示和具体冲突文案。
- 给冲突块添加清晰的红色边框或角标。
- 不把首尾相接（例如 10:00 结束、10:00 开始）误判为冲突。

### 4. 今日页面整合

- 今日任务序列同时展示课程和个人日程，并按开始时间排序。
- “下一项”从课程和个人日程中选择真正最早的一项。
- 清楚标明来源是“课程”还是“日程”。
- 没有安排时提供“创建日程”入口。

### 5. 工程与视觉

- 延续现有高明度工业终端设计，不新建另一套视觉语言。
- 使用现有设计令牌、硬边面板、模块编号和状态颜色。
- 页面与业务计算分离；时间解析、排序、冲突和时间轴分栏放入纯函数模块。
- TypeScript 严格模式保持通过。
- 不引入后端，不申请通知权限，不加入账号或追踪代码。
- 保持 PWA 离线可用。

## 测试要求

新增自动化测试覆盖：

- 时间格式和结束时间校验。
- 日程排序。
- 日程与日程冲突。
- 日程与课程冲突。
- 首尾相接不冲突。
- 时间轴重叠分栏。
- v1 本地数据迁移到包含 `events` 的新结构。
- 浏览器中创建、编辑、刷新保留、删除个人日程。
- 390px 手机日程页和 1440px 桌面日程页无页面级横向滚动。

## 验收标准

1. 现有课程、导入、撤销和离线功能不回归。
2. 可以从导航进入日程页并切换日期。
3. 可以点击时间段创建日程并完整编辑。
4. 日程刷新后仍存在，删除后不再出现。
5. 课程与日程在同一时间轴中正确定位。
6. 冲突检测与首尾边界正确。
7. 旧版本地数据可以无损迁移。
8. 今日页面正确合并课程和日程。
9. 格式、类型、单元测试、生产构建和端到端测试全部通过。
