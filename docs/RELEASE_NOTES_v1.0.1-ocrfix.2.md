# 课间 v1.0.1-ocrfix.2 · 课表扫描修复测试版

这是一版实验性修复，重点处理南信大移动教务系统课表截图中的网格定位失败和文字识别错误。安装包使用与已发布 v1.0.1 相同的正式签名，Android versionCode 为 4，可以覆盖安装并保留本地课程与日程。

## 本次改进

- 根据截图中的网格线计算行高；浅色网格线无法稳定定位时，使用已校准的完整周视图比例回退。
- 兼容底部第 11 节边界被屏幕截断、深色选中列中的白字，以及上下相邻且颜色相同的课程。
- 防止三节连堂课程被误拆成两门课。
- 使用完整简体中文 OCR 模型，加强浅色文字、教室数字和罗马数字的识别；教室后附带的文字会提示人工核对。
- 截图仍在设备本地处理，不上传，也不需要教务系统账号。

## 验证范围

- 用户提供的同一学期 18 张周课表截图全部生成识别草稿，未出现网格定位失败，共检测 203 个课程块。这是版式兼容性结果，并不代表 203 个课程字段都经过人工标注或全部正确。
- 最初提供的一张基准截图及其缩放、顶部偏移版本，11 门课程的名称、教室和节次均与人工答案完全一致。
- 51 项单元测试、8 项 Edge 浏览器流程测试、类型检查、格式检查和生产构建通过；APK 的签名与文件对齐校验通过。
- 尚未完成 Android 真机验收。识别仍仅针对南信大移动教务系统的完整竖屏周课表，其他同学、设备和教务系统可能出现错字或漏识别。请在保存前逐项校对草稿。
