# 文字识别修复记录

日期：2026-09-22。测试包版本：`1.0.1-ocrfix.2`（Android versionCode 4）。

## 问题与修复

原实现按屏幕比例裁切。不同周截图虽然都是 1080×2400，但课表网格的实际行高并不完全相同；固定坐标会越靠下偏移越大，最终切掉课程第一行。现在优先利用空白列中可见的横向网格线拟合顶部与行高，并支持第 11 节下边界超出截图；无法取得足够网格线时再使用已校准的版式比例。

第一次修复把完整网格线检测设成硬性前置条件。Android WebView 对浅色网格的像素结果与桌面浏览器存在差异，导致用户的有效南信大截图被统一拦截。第二次修复保留实际网格定位，并在其失败时使用由原图校准的南信大完整周视图比例；只有回退位置仍检测不到课程色块时才报错。回退路径会在识别提示中要求重点核对星期和节次。

浅色字经简单灰度和对比度处理后仍容易丢失笔画；原压缩模型还会把清晰的中文、数字识别错误。现在按课程背景与文字的最大颜色通道差增强笔画，放大两倍并添加白边，使用完整中文模型及单块排版模式。模型地址和缓存键已更新，防止旧模型被继续使用。完整离线资源约 54 MiB，体积比旧版增加。

罗马数字原来会被清洗规则删除，现在保留，并对 OCR 识别为竖线或“工”的独立字符检查原图笔画，仅在字形支持时恢复 I/II/III，不根据课程名称猜测级别。教室后额外文字（例如参考图中的“日语（一）”“篮球”）会展示核对提示，不当作已经确定的另一门课程。

补充的整学期样本还暴露出两类边界：当前日期所在列可能使用深色选中背景和白色文字；相邻两门同色课程可能被当作一块连堂课。修复版会按背景明暗选择文字差分方向，并仅在可见分隔线两侧都至少保留两节时拆分课程块，避免把三节连堂课误拆成 `2+1`。常见楼名和同一课程的稳定错字只做范围很小、可测试的后处理，不用课程名称反向猜测节次或教室。

## 内容级验证

使用用户最初提供的 1080×2400 南信大课表截图逐项人工转录课程名、教室和星期节次，按字符串完全匹配统计。全角括号及 Unicode 罗马数字仅做标准化比较；不是按 OCR 自报置信度评估。原图含 11 个课程块。

| 测试输入                      | 课程名完全正确 | 教室完全正确 | 名称、教室和节次同时正确 |
| ----------------------------- | -------------- | ------------ | ------------------------ |
| 已发布 v1.0.1 原识别器 + 原图 | 0/11           | 3/11         | 0/11                     |
| 修复版 + 原图                 | 11/11          | 11/11        | 11/11                    |
| 修复版 + 原图缩小至 810px 宽  | 11/11          | 11/11        | 11/11                    |
| 修复版 + 顶部增加 60px        | 11/11          | 11/11        | 11/11                    |

“完全正确”意味着任意一个错字就判该字段错误，因此不能将这张表解读为旧版的逐字错误率或修复版对所有课表都达到 100%。三个修复场景来自同一张原图，尚不构成多学校、多用户样本集。

用户随后补充了同一学期第 1–18 周的 18 张原始截图，覆盖稀疏周、深色选中列、三节连堂、相邻同色课程以及底部网格被屏幕裁掉的情况。批量回归结果为：18/18 张生成识别草稿、0 张网格定位失败，共检测 203 个课程块；逐项抽查及跨周一致性复核后，已修正相邻课程合并、三节课误拆、深色白字和少量稳定错字。此数据用于同一所学校版式内的兼容性验证，仍不能外推到其他教务系统。

测试脚本：`scripts/benchmark-ocr.mjs`；本地详细结果：`test-results/ocr-accuracy.json`（忽略提交）。原截图没有复制进仓库。另用独立生成的浅色中文课表验证“线性代数”“计算机网络”等未出现在参考图中的课程，检查具体名称、教室、罗马数字，以及浏览器断网后的识别。

本次验证：51 项单元测试、8 项 Edge 端到端测试、类型检查、格式检查和生产构建通过。保留课程编辑、导入合并、刷新保存、撤销保护和个人日程回归。浏览器手机尺寸测试不等同于 Android 真机测试。

## 手机复测

安装 `artifacts/kejian-v1.0.1-ocrfix.2.apk`，覆盖之前使用同一正式签名的应用；无需卸载或清空数据。设置页显示“网格兼容修复测试版”。重新选择原截图识别，尤其检查课程第一行、教室数字、星期节次和罗马数字。以前已经导入的错误数据不会被此次更新自动修改，需人工修正或按已有撤销机制重新导入。

本修复包供本地验收，尚未提交、推送或替换 GitHub 的 v1.0.1 Release。仍只适配南信大完整竖屏周课表；其他学校和明显不同版式不在本次准确率结论范围内。
